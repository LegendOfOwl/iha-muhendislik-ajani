# Araştırma arşivi kayıtları

- İlk Python indirmesi ağ sandbox'ında engellendi; izinli ağ erişimiyle tekrarlandı.
- arXiv için Python güven deposu sertifikayı doğrulayamadı. Windows HTTPS güven deposuyla indirildi; TLS doğrulaması kapatılmadı. LAVA doğrudan arşiv indirimi yine başarısızdır; sayfa web aracıyla okunmuştur.
- İlk yerel denetim, özgün Fortran dosyasının UTF-8 olmayan yorum baytı nedeniyle metin okumada durdu. Kontrol yalnız ASCII seçenek adının varlığı olduğundan bayt dizisi denetimine çevrildi; kaynak dosya baytları değiştirilmedi. Bu bir CFD hatası veya fizik teşhisi değildir.
- Bu görevde yeni CFD koşusu başlatılmadı; eski mühürlü tahminler ve değerlendirmeler değiştirilmedi.
